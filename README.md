# PyQuest — Interactive Python Learning Game 🧙‍♂️

Welcome to **PyQuest**, a browser-based, gamified Python learning experience designed to help beginners master core Python concepts faster than traditional tutorials!

## 🌟 Features

- **No Installation Required:** Run Python entirely in your browser using Skulpt.js!
- **Interactive Story Mode:** Learn concepts by solving narrative-driven quests.
- **Instant Feedback:** Built-in challenge validation tells you exactly what went wrong.
- **Premium UI:** Beautiful dark mode interface with smooth animations and dynamic layouts.
- **Gamified Progression:** Earn XP, level up your wizard, and collect badges for completing worlds.
- **Syntax Highlighting:** Real-time Python formatting using CodeMirror.
- **Local Save:** Your progress is automatically saved to your browser so you never lose your spot.

## 🚀 Getting Started

Since the entire application runs client-side in the browser:

1. Open the project folder.
2. Double-click on `index.html` to open it in your favorite modern web browser (Chrome, Firefox, Edge, Safari).
3. Start your quest!

## 🗺️ Current Worlds

1. **The Awakening** (Variables & Data) - Learn the fundamentals of storing information.
2. **The Scrolls** (Strings & Input) - Learn how to manipulate text and magic words.

*(More worlds covering Conditionals, Loops, Functions, and Data Structures can be added following the pattern in `game.js`!)*

## 🛠️ Built With

- **HTML5 / CSS3 / Vanilla JavaScript** - Lightweight and performant frontend.
- **Skulpt.js** - Client-side Python execution environment.
- **CodeMirror** - Powerful text editor for the web.
- **Google Fonts** - Inter and Fira Code for premium typography.

Enjoy your quest to become a Python Wizard! 🪄
